# 余痕 · Remnants

> 在线试玩：**https://mcqyl.github.io/yuhen1/**

一款**打开网页就能玩**的第一人称叙事探索小游戏。你走进一片被雾分成三层的旷野，地上散着十三件旧物；捡起一件，就要看完一段不能跳过的回忆。也可以什么都不碰，直接从旁边走过去。看过多少，决定你会遇到哪种结局。

---

## 特色

- **第一人称沉浸**：没有第三人称背影，没有任务栏，没有收集百分比。
- **三层雾**：能见度约 60 m → 25 m → 12 m，分别以断墙缺口、横倒枯树、最后一道门为界。
- **十三件碎片**：发圈、纸条、旧杯子、铜铃、坏伞、停摆的表、没送出的钥匙、涂黑的日记页、撕坏的信、裂开的陶瓷鸟、旧车票、摔裂的相机、空首饰盒。
- **两种结局**：第三段看过 ≥3 段回忆，并且看过「空首饰盒」→ 雾散；否则 → 薄雾还在。
- **完全本地化**：Three.js 已放进仓库，场景、贴图、石头、草、树、声音全部由代码生成；无后端、无构建、无外部网络请求。
- **可调试**：浏览器控制台提供 `__YH.tp(x, z, y)`、`__YH.seenAll()`、`__YH.stage(n)` 等验收指令。

## 怎么玩

### 在线

直接打开 <https://mcqyl.github.io/yuhen1/>。推荐桌面版 Chrome / Edge，点击画面后鼠标会被锁定，按 `Esc` 释放。

### 本地

```bash
git clone https://github.com/mcqyl/yuhen1.git
cd yuhen1
# 方式一：直接双击 index.html
# 方式二：用任意静态服务器，例如
python -m http.server 8000
# 然后打开 http://localhost:8000
```

浏览器需要支持 **WebGL**。第一次进入会有 1–3 秒程序化贴图生成，出现「正在显影…」是正常现象。

### 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `S` 或 `↑` / `↓` | 前进 / 后退 |
| `A` / `D` 或 `←` / `→` | 左右侧移 |
| 鼠标 | 转头（点击画面锁定指针，`Esc` 释放） |
| `空格` | 攀上矮墙 / 树干 / 石台 |
| `E` | 捡起碎片 · 放下手里的东西 |

走得慢是刻意设计的（1.32 m/s）。站到高处雾会薄一点，能多看十几米。

## 托管说明

本仓库只保留可玩页面，已启用 **GitHub Pages**，发布源为 `main` 分支的根目录。每次向 `main` 推送后，页面会在约 1–2 分钟内自动更新，不需要额外构建步骤。

## 说明

- 场景、贴图、声音均由代码生成，没有外部美术资源，因此风格是「低多边形 + 浓雾 + 水彩回忆」，不是写实。
- 回忆片是程序化插画动画，人物是剪影、不露正脸，演出上不给总结字幕。
- 游戏不存档、不计数、不评价；两个结局没有好坏，只有「你选择记住多少」。
