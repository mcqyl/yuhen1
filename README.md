# 余痕 · Remnants

> 在线试玩：**https://mcqyl.github.io/yuhen1/**

第一人称回忆漫游。中央一片荒原，五条路通向五段人生，十三件旧物，四种结局。

故事来自《他记忆最开头的画面，永远定格在外婆的灶台》：外婆的荷包蛋、陈姨的油条、周老师的红字、巷口的来福、病房里那句「我不饿」。

---

## 怎么玩

### 在线

直接打开 <https://mcqyl.github.io/yuhen1/>。推荐桌面版 Chrome / Edge，点击画面后鼠标会被锁定，按 `Esc` 释放。

### 本地

```bash
git clone https://github.com/mcqyl/yuhen1.git
cd yuhen1
# 方式一：直接双击 index.html
# 方式二：用任意静态服务器，例如
python -m http.server 8000
# 然后打开 http://localhost:8000
```

浏览器需要支持 **WebGL**。第一次进入会有 2–4 秒程序化贴图生成（石材、树皮、地面、法线、粗糙度、环境球）。

### 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `S` 或 `↑` / `↓` | 前进 / 后退 |
| `A` / `D` 或 `←` / `→` | 左右侧移 |
| 鼠标 | 转头（点击画面锁定指针，`Esc` 释放） |
| `空格` | 攀上矮墙 / 树干 / 石台 / 窗台 / 上铺 |
| `E` | 捡起碎片 · 放下手里的东西 |

走得慢是刻意设计的（1.32 m/s）。

### 画质

标题页右下可选「流畅 / 标准 / 电影」，也可用 `?q=low|med|high` 直接指定。渲染走 HDR 后处理管线：亮部提取 → 两级高斯模糊 → 合成 → ACES → 调色 → 暗角 → 颗粒。帧时间连续超过 27 ms 会自动降一档。

## 地图

中央是**回忆荒原**：一圈立石，五道缺口，每道缺口对着一条土路，路的尽头是一片封起来的回忆区。走进去，雾和光就换成那一段人生的颜色。

| 区 | 名字 | 里面有什么 | 光 |
| --- | --- | --- | --- |
| 童年 | 灶台与银杏院 · 旧巷早点摊 | 巷口摊子、桥洞、灶房、水井、晾衣绳、老银杏与落叶 | 午后暖光，雾最薄 |
| 少年 | 小学办公室 · 初中教室 · 高中走廊 | 办公室（窗台可攀）、课桌、落地窗长廊 | 中性自然光，慢慢转冷 |
| 亲情与失去 | 旧家饭桌 · 医院长廊 · 大学宿舍 | 四把椅子的饭桌、白墙长廊与病床、上下铺 | 冷白，雾最厚 |
| 成年疏离 | 城市餐厅 · 拆迁围挡 · 出租屋浴室 | 长桌与吊灯、围挡、洗手台与镜子 | 低照度蓝灰 |
| 终章 | 柜子深处 · 一条向前的长路 | 柜子、落叶长路、尽头的门 | 淡金漫射 |

## 十三件碎片

| 区 | 碎片 | 位置 | 层级 |
| --- | --- | --- | --- |
| 童年 | 磨亮的灶台碎砖 | 灶台上 | 主路 |
| 童年 | 浸透油的纸袋残片 | 早点摊旁的地上 | 角落 |
| 少年 | 泛黄的作业本残页 | 办公室窗台 | **高处，需攀爬** |
| 少年 | 揉皱又展平的纸条 | 初中课桌抽屉 | 角落 |
| 少年 | 试卷的一角 | 高中走廊窗边 | 主路 |
| 亲情 | 掉漆搪瓷碗的瓷片 | 病房床头柜 | 主路 |
| 亲情 | 白搪瓷杯口的碎块 | 宿舍上铺 | **高处，需攀爬** |
| 亲情 | 褪色的狗粮袋残片 | 石墩旁的草丛 | 角落 |
| 成年 | 打印模糊的餐饮小票 | 餐桌桌面 | 主路 |
| 成年 | 银杏的白色断根 | 围挡缝隙 | 角落 |
| 成年 | 镜面玻璃碎屑 | 洗手台边缘 | 主路 |
| 终章 | 空木盒的木屑（真相节点） | 柜子底部 | 主路 |
| 终章 | 干枯的银杏叶 | 长路起始处 | 主路 |

- **不捡就没有回忆**：一件都不拿，直接走到终章的门，草地就是空的。
- **捡起来就进入回忆片**：全屏水彩动画，不能跳过。看完东西在手里，可以带着走完全图，也可以随时按 `E` 放回原处。
- **高处的要爬**：站到窗台 / 上铺底下按 `空格` 攀上去，才够得着。

## 结局

| 条件 | 结局 | 画面 |
| --- | --- | --- |
| 一件都没捡 | **ENDING 01 / 什么也没带走** | 一片空的浅灰草地，雾一直都在 |
| 十三件全部看过，手里还留着一块 | **ENDING 03 / 雾散之后** | 雾退到天边，光是暖的，脚下是金色草地 |
| 十三件全部看过，空着手 | **ENDING 02 / 我看过了，也放下了** | 雾散一半，碎片一块块沉进草里，人往前走 |
| 只看了一部分 | **ENDING 04 / 薄雾还在** | 雾停在原来的地方，不浓也不淡 |

判定在走进终章区尽头那道门时触发。

```
└── assets/title.jpg    标题背景概念图
```

## 说明

- 场景、贴图、石头、草、树、声音全部由代码生成，没有外部美术资源文件，取向是「程序化写实 + 浓雾」。
- 回忆片是程序化插画动画，人物是剪影、不露正脸，演出上不铺字幕条；只有极少数句子以手写体浮在画面下方。
- 游戏不存档、不计数、不评价；四种结局没有好坏，只有「你选择记住多少」。
- 验收指令：`__YH.tp(x, z, y)` 传送 · `__YH.view(yaw, pitch)` 转头 · `__YH.stage(n)` 切光（0–4 五区、5 荒原、6 结局） · `__YH.place(i)` 落到第 i 个区门口 · `__YH.seenAll()` 标记全部看过 · `__YH.dropAll()` 全部放下 · `__YH.state()` 看状态 · `__YH.quality('low'|'med'|'high')` 切画质 · `__YH.stats()` 看几何体/贴图数量。
