# 余痕 · Remnants

> 在线试玩：**https://mcqyl.github.io/yuhen1/**

第一人称回忆漫游。雾分三段，十三件旧物，三种结局。

故事来自《他记忆最开头的画面，永远定格在外婆的灶台》：外婆的荷包蛋、陈姨的油条、周老师的红字、巷口的来福、病房里那句「我不饿」。

---

## 怎么玩

### 在线

直接打开 <https://mcqyl.github.io/yuhen1/>。推荐桌面版 Chrome / Edge，点击画面后鼠标会被锁定，按 `Esc` 释放。

### 本地

```bash
git clone https://github.com/mcqyl/yuhen1.git
cd yuhen1
# 方式一：直接双击 index.html
# 方式二：用任意静态服务器，例如
python -m http.server 8000
# 然后打开 http://localhost:8000
```

浏览器需要支持 **WebGL**。第一次进入会有 2–4 秒程序化贴图生成（石材、树皮、地面、法线、粗糙度、环境球）。

### 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `S` 或 `↑` / `↓` | 前进 / 后退 |
| `A` / `D` 或 `←` / `→` | 左右侧移 |
| 鼠标 | 转头（点击画面锁定指针，`Esc` 释放） |
| `空格` | 攀上矮墙 / 树干 / 石台 |
| `E` | 捡起碎片 · 放下手里的东西 |

走得慢是刻意设计的（1.32 m/s）。站到高处雾会薄一点，能多看十几米。

### 画质

标题页右下可选「流畅 / 标准 / 电影」，也可用 `?q=low|med|high` 直接指定。渲染走 HDR 后处理管线：亮部提取 → 两级高斯模糊 → 合成 → ACES → 调色 → 暗角 → 颗粒，材质为程序化 PBR。帧时间连续超过 27 ms 会自动降一档。

## 规则

- **三段**：雾的能见度约 60 m → 25 m → 12 m，界线依次是断墙缺口、横倒的枯树（要翻过去）、最后一道门。
- **十三件碎片**：
  - 第一段（还暖和的时候）4 件：磨亮的灶台碎砖、浸透油的纸袋残片、泛黄的作业本残页、揉皱又展平的纸条。
  - 第二段（开始失去）4 件：试卷的一角、掉漆搪瓷碗的瓷片、白搪瓷杯口的碎块、褪色的狗粮袋残片。
  - 第三段（都不在了）5 件：打印模糊的餐饮小票、银杏的白色断根、镜面玻璃碎屑、空木盒的木屑（真相节点）、干枯的银杏叶。
- **不捡就没有回忆**：一件都不拿，那一段就是空白，可以直接走过去。
- **捡起来就进入回忆片**：全屏水彩动画，不能跳过。看完东西还在手里，可以带着走，也可以放回原处。
- **跨段时手里的东西会留在雾那边**（按设定，它回不去）。
- **三种结局**：
  - 十三件全部看过 → 雾散了（释然）
  - 一件都没捡 → 空的草地（什么也没带走）
  - 其余 → 雾没有散（薄雾还在）

```

```

## 托管说明

本仓库只保留可玩页面，已启用 **GitHub Pages**，发布源为 `main` 分支的根目录。每次向 `main` 推送后，页面会在约 1–2 分钟内自动更新，不需要额外构建步骤。

## 说明

- 场景、贴图、石头、草、树、声音全部由代码生成，没有外部美术资源文件，取向是「程序化写实 + 浓雾」。
- 回忆片是程序化插画动画，人物是剪影、不露正脸，演出上不铺字幕条；只有极少数句子以手写体浮在画面下方。
- 游戏不存档、不计数、不评价；三种结局没有好坏，只有「你选择记住多少」。
- 验收指令：`__YH.tp(x, z, y)` 传送 · `__YH.view(yaw, pitch)` 转头 · `__YH.stage(n)` 切段 · `__YH.seenAll()` 标记全部看过 · `__YH.state()` 看状态 · `__YH.quality('low'|'med'|'high')` 切画质 · `__YH.stats()` 看几何体/贴图数量。
